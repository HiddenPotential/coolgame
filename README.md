# ⛳ Wacky Golf

Mini golf, but nothing is a ball and nothing is a club.

Nine holes, each with its own thing to hit: a rubber duck that floats, a raw egg that cracks, sticky pizza, a slippery donut, a heavy watermelon, a frog that hops off on its own, a floppy sock, bouncy cheese, and a banana that curves.

Hit them with:

| Club | What it does |
| --- | --- |
| 🥖 Baguette | Reliable, straight shot |
| 🐟 Wet Fish | Extra power, terrible aim |
| 🍳 Frying Pan | Lobs over water and sand |
| 🐔 Rubber Chicken | Curves the shot (randomly left or right) |

## Play

Open `index.html` in a browser. No build step, no dependencies.

- Drag anywhere on the course to pull back and aim, then let go to swing.
- Keys `1`–`4` pick a club, `M` mutes, `Esc` cancels a shot.
- Add `?hole=5` to the URL to jump to a hole for practice.
